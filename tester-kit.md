# Cut Crew — Tester kit

## 1. Share the app
1. Open Cut Crew → tap **Share** (top of the page) → add the tester's email (or copy the link and turn on access for them)
2. The tester needs a **free Claude account** and must be signed in — the AI moment finder runs on their account
3. First time they tap "Find the moments", Claude asks them to allow AI — they tap **Allow**

## 2. Message to send (LINE / WhatsApp)
> hey I'm building an app called Cut Crew — you paste a YouTube video and AI finds the craziest moments and writes the hooks for TikTok. can you try it for 10 min? I'll send you the link. just use it like normal, I'm only watching, I won't help 🙏

## 3. The task to give them (say only this)
> "Pick any long YouTube video you'd want to clip — a podcast or a stream. Use Cut Crew to find 2 clips worth posting, and get one ready to post."

Then **say nothing**. Don't point, don't explain.

## 4. What to write down while you watch

| Time | Where they were | What happened (paused / frowned / asked / tapped wrong thing) |
|------|-----------------|---------------------------------------------------------------|
|      |                 |                                                               |
|      |                 |                                                               |
|      |                 |                                                               |

Watch especially for:
- Do they find the **AI moment finder** on their own?
- Can they get the **transcript** from YouTube without help?
- Do they trust the AI's moments — or go check the video?
- Do they **save** a moment and **copy the post text**?
- Do they tap the dimmed **SOON** tiles?

## 5. Ask after (5 questions)
1. What was annoying?
2. Would the AI's moments actually get views? Which one would you post?
3. Which hook would you pick, and why?
4. What did you expect to happen that didn't?
5. Would you use this again for real clipping? What would stop you?

## 6. Stopwatch (main job)
**Main job:** from pasting a YouTube link → one clip ready to post.
- Before (doing it by hand: watch the video, find a moment, write a hook): ______ min
- After (with Cut Crew + AI): ______ min
